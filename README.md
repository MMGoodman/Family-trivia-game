# 🎉 משחק טרוויה משפחתי

מערכת טרוויה לחופשות ומסיבות משפחתיות: המנחה מקרין שאלות על מסך גדול,
כל קבוצה (משפחה) מרימה פתק עם התשובה שלה, והמנחה מקליד את התשובות —
הניקוד מחושב ומוצג אוטומטית.

## איך זה עובד

- **מסך ניהול** — למנחה, על הלפטופ: רישום תשובות, חשיפה, מעבר בין שאלות.
- **מסך הקרנה** — נפתח בחלון נפרד, גוררים למקרן/טלוויזיה. מתעדכן לבד.
- הניקוד **מחושב מהרישומים** ולא נשמר — תיקון של כל טעות מעדכן הכל מיד.
- כל משחק ("חופשת קיץ", "מסיבת חנוכה") נשמר בענן וניתן לעריכה בכל רגע.

## הקמה חד-פעמית

1. **בסיס נתונים**: היכנס ל-[Supabase](https://supabase.com) → הפרויקט שלך →
   SQL Editor → הדבק את התוכן של `supabase-schema.sql` → Run.
2. **פרטי חיבור**: ודא שבקובץ `.env` יש את ה-URL וה-publishable key של הפרויקט:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_KEY=sb_publishable_xxxx
   ```
3. **הרצה מקומית**:
   ```
   npm install
   npm run dev
   ```
4. גלוש ל-http://localhost:5173, צור חשבון, צור משחק — ותתחיל להכניס שאלות.

## ערב המשחק — צ'קליסט

1. לפתוח את המערכת ולהתחבר (אם הפרויקט "ישן" שבוע — להעיר אותו בלוח של Supabase).
2. ללחוץ "שחק" על המשחק → "פתח מסך הקרנה" → לגרור את החלון למקרן → F11.
3. להדפיס/להכין לכל קבוצה פתקים עם א' ב' ג' ד'.
4. "התחל את המשחק" — ומכאן הכל מהמסך שלך: רישום, חשיפה, הבא.

## גיבוי

בכל משחק יש כפתור **ייצוא** שמוריד קובץ JSON עם כל השאלות והקבוצות.
שמור אותו בדרייב/וואטסאפ — ואפשר לייבא אותו בחזרה בכל מחשב.
